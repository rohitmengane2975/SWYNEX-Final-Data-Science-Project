# SWYNEX Final Data Science Project

## Project Title
Titanic Survival Prediction — End-to-End Data Science Project

## Problem Statement
The goal of this project is to analyze Titanic passenger data and build a machine learning model to predict passenger survival.

## Objectives
- Prepare and clean the dataset.
- Perform Exploratory Data Analysis (EDA).
- Identify important survival patterns.
- Build and evaluate a Logistic Regression model.
- Discuss model limitations and conclusions.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab
- GitHub

## Dataset
The project uses the Titanic passenger dataset containing information such as passenger class, age, sex, fare, family members, and survival status.

## Project Workflow
1. **Data Preparation:** Handled missing values and checked duplicate rows.
2. **EDA:** Analyzed survival rates by gender and passenger class, and explored age, fare, and numerical relationships using visualizations.
3. **Modeling:** Built a Logistic Regression baseline model.
4. **Evaluation:** Evaluated the model using accuracy, confusion matrix, precision, recall, and F1-score.
5. **Conclusion:** Summarized key findings and model limitations.

## Model Performance
The baseline Logistic Regression model achieved approximately **80.45% accuracy** on the test dataset.

## Key Findings
- Overall survival was approximately 38.4%.
- Female passengers had a higher survival rate than male passengers.
- Passenger class was associated with survival differences.
- Age and fare distributions provided additional insights into the passenger data.

## Limitations
- Logistic Regression is a baseline model; other algorithms may perform differently.
- The model uses only selected features from the available dataset.
- Accuracy alone does not fully describe model performance.

## Files

## Conclusion
This project demonstrates an end-to-end data science workflow, from data preparation and exploratory analysis to machine learning and model evaluation.
